# 场景图片编辑与组合动效设计

用户希望已完成项目可逐场景修改图片和运动，同时保持 MP4 与剪映草稿一致。

- 动效按透明度、水平位移、垂直位移、缩放四组选择；组间可组合，组内方向互斥。原有单一预设继续兼容；分层视差可分别控制背景与人物。
- 角色是否出镜自动决定：语义分段沿用模型结果；固定分段且没有配置模型时默认不出镜。任务不再为出镜确认而暂停。
- 场景编辑页展示每张原图、完整 Draw Things 命令、各图层动效；允许编辑命令中的提示词、模型、尺寸、步数和 seed，上传图片，异步生成候选图，确认后替换或舍弃。
- 生图任务进入单工作者持久化队列；页面切换不影响任务。命令必须解析并验证，不通过 Shell 执行任意字符串。
- 确认替换后保存旧版，并重建当前项目的 MP4 和剪映草稿。已经登记到剪映的副本只通过明确的同步操作更新。
- 剪映关键帧与 FFmpeg 使用同一份运动参数；对透明度、上下位移和组合场景建立工程结构及实际渲染测试。
