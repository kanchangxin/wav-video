# 单主角角色档案设计

目标：用户可在本地创建和复用一套主角参考图，并在场景生图时稳定传入身份参考、固定 seed 和提示词后缀。

方案：使用项目内 `characters/<档案目录>/` 存储角色资料。正面半身照先生成并确认；侧脸与全身分别从已确认的正面照生成，也允许导入现有图片。场景生成先产出计划，由用户确认每段是否有主角，再进行 Draw Things 生图。角色图和参数进入任务快照与日志。

约束：第一版只支持一个主角；模型和步数沿用现有 Draw Things CLI 机制；seed 默认 271829；参考图和固定后缀可留空；没有角色档案的任务沿用现有流程。角色图目录在项目的 `characters/` 下，可修改和在 Finder 中打开。固定 seed 与参考图只能提高一致性，不能保证完全相同。

取舍：直接给所有场景传图最简单，但会让主角进入不该出现的画面。采用一次场景确认，增加一步操作，换取可控的出镜判断。角色参考图优先使用正面照，其余角度作为辅助，避免未经确认的图造成身份漂移。
