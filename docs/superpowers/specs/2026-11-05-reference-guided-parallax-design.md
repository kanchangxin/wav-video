# 原图引导的分层视差设计

## 意图与范围

为现有分层视差制作更贴合原图的空背景，并允许用户在场景编辑页选择两种前景制作方式。画面运动仍由现有 FFmpeg 与剪映关键帧实现；本次修改聚焦图层素材的生成、预览和替换。

## 方案比较

1. **两层都由 Qwen 重新生成。** 工作流统一，但人物面容、服装、姿态和原图可能不一致，透明通道也需额外校验，成本较高。
2. **AI 补背景、原图抠前景。** 背景可补全被遮挡区域；前景保留原图像素，成本较低。无法修复原图中的遮挡或改变人物姿态。
3. **混合方案（选用）。** 背景通过参考图编辑；单人镜头默认使用原图抠图，骑乘、手持武器等复合主体镜头优先尝试 AI 前景。用户可在编辑页使用另一种方式重新生成候选。用户已明确希望保留两种前景方式。

## 工作流

### 新任务的分层视差

先生成场景原图。空背景默认使用本地已下载的 Qwen Image 2.1 Turbo（若没有则允许选其他已下载且支持参考图的模型），把场景原图作为 `--image` 1，用明确的编辑指令移除与前景相同的可见主体并补全其遮挡区域，尽量保持机位、透视、构图、光线和建筑细节。背景生成模型可与场景原图模型不同。第一版只补原图内部遮挡，平移沿用已有放大裁切，不承诺生成原图边界外的新景。

单人镜头优先从同一原图经现有 `person_cutout` 制成透明 PNG。场景提示词明确涉及骑乘、坐骑、手持物等复合主体时，优先走参考图 AI 前景；这个自动判断只用于选择初始方式，结果必须记录并允许在编辑页改用另一种方式。AI 前景需保留整组主体（人物、坐骑、道具），输出有效 alpha；若没有可靠透明通道，不用只识别人像的工具强行处理复合主体，而是记录失败并退回单图动效。素材生成和校验成功后，进入现有 MP4/剪映构建流程；原图及生成参数保留，供编辑页回看和重新生成。任何图层失败时记录原因，并沿用已有单图动效回退。

### 已完成任务的场景编辑

在“空背景”层提供“以场景原图生成空背景”快捷操作：自动填入 `--image <场景原图>`、推荐模型和可编辑提示词，沿用当前异步候选图队列。候选图不覆盖现有图层；用户预览后采用或舍弃。在“透明人物”层提供“从原图抠图”和“AI 生成前景”两个入口。后者将原图作为参考，提示保留目标人物、坐骑及道具并去除背景；对单人镜头，若模型输出没有有效 alpha，可再用现有抠图工具处理。复合主体输出若没有有效 alpha，应提示失败并允许重试或上传透明 PNG。AI 前景也作为候选图，由用户决定是否替换。上传图片、编辑完整 Draw Things 命令、旧图版本保存继续可用。

### 命令与记录

图层命令应完整展示 `--model`、`--prompt`、尺寸、seed、`--image` 等用户可编辑参数。实测发现本机 Draw Things CLI 的首图 canvas 模式几乎不执行 Qwen Image 2.1 Turbo 的移除指令，因此参考图编辑要让首图进入 moodboard 模式。为避免模型复制白色边框，用场景边缘像素扩展 64 像素，使首图宽高比与输出不同；普通角色身份参考图保留原处理。背景以原图宽高比生成，现有准备阶段会放大裁切出视差运镜的画幅；生成时在记录中保存来源图、模型、提示词、尺寸、seed、生成方式和指纹，原图变化时缓存自动失效。日志记录最终提示词、完整命令、输出路径及失败原因。

## 约束与验收

- Qwen 的参考图编辑能力有官方示例，但实测 Qwen Image 2.1 Turbo 对骑马场景的空背景仍留下马匹残影；专用 Qwen Image Edit 2511 在同一素材上移除更干净，但一次约 5 分钟。用户可在场景编辑页改模型、检查候选图并重试；不能把生成结果当成无误的背景。
- 现有 `person_cutout` 会分离画面中的所有可识别人像，但不会保留马或武器。单人抠图模式的空背景提示词需要去除被抠出的所有人像；复合主体 AI 模式则需要去除其整组主体。第一版前景整体作为一个图层运动，不做多人独立分层。
- 保证场景原图、空背景和透明前景的宽高比及对齐关系；透明前景必须通过 alpha 校验。AI 前景即使生成透明，也只作为候选。
- 现有项目与已有 scene JSON 兼容。失败或未启用该方式的项目沿用原流程。MP4 与剪映共用已确认的图层及现有运动参数。
- 用小样本实测本机 Draw Things 对 Qwen Image 2.1 Turbo 的 `--image` 编辑与透明 PNG 输出；自动化测试覆盖参数传递、候选图状态、alpha 校验、缓存失效和回退。实测质量只作为用户可预览的候选，不设自动“合格”结论。

## 暂不包含

手绘 mask、针对单个人的精确实例分割、多人独立图层及深度图。后续若参考图编辑对复杂场景不稳定，再引入 mask 引导的修补/扩图工具。
